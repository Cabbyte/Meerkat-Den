# Meerkat Den

Meerkat Den 的 macOS 下载与自动更新入口。

支持 macOS 14 或更新版本，仅支持 Apple Silicon Mac（M 系列芯片）。

[下载最新版本](https://github.com/Cabbyte/Meerkat-Den/releases/latest) · [所有版本与更新说明](https://github.com/Cabbyte/Meerkat-Den/releases) · [使用说明](使用说明.md)

下载 ZIP，解压后将完整的 Meerkat Den.app 拖入“应用程序”。首次使用时按功能提示授权。可用同版本的 SHA256.txt 核对下载文件。

从不支持自动更新的旧版本升级，需要手动安装一次。此后可从应用菜单或“软件更新”页面检查新版；默认每天检查并提示安装，自动下载与安装默认关闭。

更新会保留配置与 Dash 绑定。已安装到 Zotero 的插件需按版本说明单独更新。
