# Meerkat Den 0.14.9

- 新增应用内更新：可从应用菜单、菜单栏菜单或“软件更新”页面检查新版本。
- 默认每天检查更新并提示安装；可选择自动下载与安装。
- Meerkat Lite 的 C1 可连续清除 Dash 绑定，C2 可交换两个 Dash 的绑定及颜色，并提供灯色与操作提示。
- 新增已绑定本机 Codex 任务的状态监看与 Lite 状态灯，默认关闭；可在应用集成中开启。提问和审批显示为待查看提醒，确认提醒不会代替你回答或批准。
- 安装包增加面向用户的安装、授权和更新说明。

需要 macOS 14 或更新系统，仅支持 Apple Silicon Mac（M 系列芯片）。

从早期版本升级，请先下载 ZIP，将完整的 Meerkat Den.app 放入“应用程序”并打开一次。此后可使用应用内更新。配置和 Dash 绑定会保留。

Zotero 插件仍需通过 Zotero 的插件管理器安装；Den 自动更新不会替换已安装的 XPI。本版无需重新安装 Zotero 插件。

首次从旧版本升级后，若“独占 F 键”的整体专用辅助服务仍未切换到新版，请在外接键盘设置中重新注册该服务，或安装后重启 Mac。按提示检查系统权限。

任务监看仅支持本机保存的 Codex 会话；待查看提醒需要安装 Hooks，并在 Codex 中审核、信任。运行中的会话可能需要重新打开。
