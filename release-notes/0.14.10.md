# Meerkat Den 0.14.10

- 新增“控制器 → Meerkat Lite → 灯效预设”页面，展示六种内置灯效。
- 支持为单个 Dash 选择颜色、亮度并短时预览；新提醒、设备输入或离开页面会结束预览。
- 支持由兼容 Lite 固件在设备端播放任务状态灯效，减少持续通信；旧固件继续使用原有颜色反馈。
- 修复操作提示淡出后可能残留透明窗口的问题。
- 保留应用内更新、Lite C1／C2 操作和本机 Codex 任务状态监看。

需要 macOS 14 或更新系统，仅支持 Apple Silicon Mac。

设备端动画和实物试灯需要支持灯效协议的 Lite 固件。Den 更新不会自动升级设备固件；旧固件仍可正常使用绑定与基础反馈，新灯效的实物效果仍待验证。

已安装 0.14.9 的用户可在“软件更新”中升级；更早版本需先手动安装支持自动更新的版本。Zotero 插件无需重新安装。
